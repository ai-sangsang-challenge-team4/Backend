# 데모 회원가입 명부

`dev` 또는 `demo-seed` 프로필로 애플리케이션을 시작하면 회원가입 검증에 사용할 수 있는
아래 명부가 멱등하게 생성된다. 이 데이터는 가입이 완료된 계정이 아니라 학교가 보유한
교사·학생 명부다.

## 학교와 학급

- 학교명: `상상중학교`
- 학교 코드: `DEMO-SANGSANG-MIDDLE`
- 학년도: 애플리케이션 시작 시점의 현재 연도
- 학급: 2학년 1반

학교와 학급의 DB ID는 실행 환경마다 달라질 수 있으므로 다음 API에서 조회한다.

- `GET /auth/schools?keyword=상상중학교`
- `GET /auth/schools/{schoolId}/classes?grade=2`
- `GET /auth/classes/{schoolClassId}/students`

## 교사 회원가입용 명부

| 이름 | 교직원 번호 |
|---|---|
| 김민지 | `SSMS-T-001` |
| 이준호 | `SSMS-T-002` |

교사는 회원가입할 때 학교, 이름, 교직원 번호를 명부와 동일하게 입력한다. 한 교직원 명부는
한 계정에만 연결되므로 이미 사용한 번호로 다시 가입할 수 없다.

## 학부모 회원가입용 학생 명부

| 학생 이름 | 학생 번호 |
|---|---|
| 김서윤 | `1` |
| 이도윤 | `2` |
| 박하린 | `3` |

학부모는 학교와 학급, 학생 번호를 선택한 뒤 학생 이름을 명부와 동일하게 입력한다.
